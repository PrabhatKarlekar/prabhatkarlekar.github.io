PAYF — Pay As You Forward Protocol

2025–2026 | ns-3, Rust, Axum, PostgreSQL, Ed25519, WASM

Designed and implemented a cryptographically verifiable packet-forwarding and monetisation protocol using ns-3 network simulation. Incorporates Ed25519-signed QoS shim headers, high-throughput FlowCache transactional caching, and PostgreSQL persistence with asynchronous Rust/Axum APIs and a Yew/WebAssembly settlement visualization dashboard.

Systems Architecture Highlights

  • Ed25519-signed QoS shim headers enabling cryptographically verifiable, per-packet billing
  • High-throughput FlowCache transactional caching layer minimizing database contention
  • PostgreSQL schema with asynchronous Rust/Axum REST APIs and Yew/WASM real-time settlement dashboard
Architecture & Protocol Spec
Protocol Pipeline
ns-3 Packet Gen → Ed25519 Shim Header → FlowCache Layer → Axum REST API → PostgreSQL Ledger → Yew/WASM UI
Security & Concurrency Highlights
  • Cryptographic Non-Repudiation: 18-byte shim header carries Ed25519 digital signature per QoS flow, preventing spoofed delivery claims.
  • Lock-Free Cache: In-memory FlowCache ring buffer absorbs line-rate simulation bursts, reducing PostgreSQL write lock contention.
  • Deterministic Settlement: WASM dashboard executes client-side cryptographic signature verification against batch settlement state.

GreyMisnomer — Verifiable Carbon Credit Registry SDK

2026 | Open-Source, Rust, RFC Protocol Design

Architecting an open-source, Rust-based registry SDK for voluntary carbon markets with protocol-level prevention of double-counting and greenwashing. Implements a Two-Proof Model combining Proof-of-Integrity (PoI) and Proof-of-Offset (PoO) with Merkle commitments and strict registry-market separation.

Protocol Spec & Two-Proof Model
Two-Proof Verification Pipeline
MRV IoT Telemetry → Proof-of-Integrity (PoI) → Sparse Merkle Tree → Proof-of-Offset (PoO) → Irreversible State Transition
Integrity Guarantees
  • Double-Counting Prevention: PoI binds cryptographic commitments of physical sequestration to unique geospatial epochs before credit minting.
  • Permanent Retirement: PoO enforces atomic, non-fungible retirement certificates with cryptographic zero-state proofs.
  • Registry-Market Separation: Decouples core registry state transitions from secondary market financial mechanics.
