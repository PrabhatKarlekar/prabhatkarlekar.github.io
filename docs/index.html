GreyMisnomer — Verifiable Carbon Credit Registry SDK

Jan 2026 | Open-Source, Rust, WebAssembly, Protocol Design

Designed an open-source, Rust-based registry protocol for verifiable carbon-credit lifecycle management with protocol-level prevention of double counting and greenwashing. Implements a Two-Proof Model using Proof-of-Integrity (PoI) and Proof-of-Offset (PoO) with Merkle commitments for verifiable project and offset lifecycle guarantees.

Protocol Spec & Two-Proof Model

Two-Proof Verification Pipeline

Project Issuance → Proof-of-Integrity (PoI) → Merkle Commitments → Proof-of-Offset (PoO) → Verifiable Lifecycle

Integrity Guarantees

  • Double-Counting Prevention: Protocol-level invariants prevent double counting and greenwashing across issuance and retirement.
  • Two-Proof Model (PoI + PoO): Proof-of-Integrity and Proof-of-Offset provide verifiable project and offset lifecycle guarantees.
  • Registry-Market Separation: Decouples core registry state transitions from secondary market financial mechanics.
